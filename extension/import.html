Import playlists

Drop in a CSV exported from Crate Digger (any version) or a .json backup. Tracks go into the playlist with the same name — new playlists are created as needed, and anything already there is skipped, so it's safe to import the same file twice.

  1. Moving from an older install? In the old version open ⚙ Settings → Export all playlists (one CSV).
  2. Drop that file here — every playlist comes across with its name.
  3. A CSV without a Playlist column (single-playlist export) goes into a playlist named after the file.
